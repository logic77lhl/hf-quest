TIP怎么读这些数字

trendingScore：近段时间的加权热度。容易被「新发布 + 社区量化包」推高，一个基座能刷出 5 个衍生版。

likes：人气，但会被人为追。名字超长的融合模型 likes 常常虚高。

downloads：真实使用量（近 30 天）。判断一个模型能不能用，先看这个量级。

pipeline_tag：任务类型。顺着它去 /tasks 找同类模型。

createdAt：太新（<1 周）别急着进生产，等社区踩坑。

点模型名会按「链接站」设置打开（默认官方），Files 里能看到权重分片和 tokenizer.json。

SYNC跨设备同步 · 私有 Gist 云存档

同一套打卡记录，多台电脑共用。token 只存在这台电脑的浏览器里，不会写进页面、不会进导出文件。

—

HOW三步接通（每台电脑做一次）

① 造一个 token
GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → 只勾 gist → 设 90 天过期。 也可以用 fine-grained token，权限只给 Gists: Read and write。

② 建存档
把 token 粘进上面的框 → 点「创建新存档」→ 得到一个 Gist ID（自动填好）。

③ 第二台电脑
打开同一个网址 → 粘同一个 token + 同一个 Gist ID → 点「立即双向同步」。以后开页面自动拉、改完自动推。

合并规则
课程勾选 / 笔记：按最后修改时间取胜（所以取消勾选也能同步）；打卡日期取并集；动作数取较大值。
但有两种情况不会自动落笔：两边都改过同一个项目（冲突），或云端会取消你本地的完成项。这两种都会先弹预览，让你裁决，再推送。

⚠️ token 等同于你 Gist 的钥匙：这台电脑的浏览器本地存储里会有明文。公用电脑别保存，用完点「清除」。
