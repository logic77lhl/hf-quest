# HF 探索打卡 · Hugging Face 系统学习路径

单文件离线网页，用来系统学 Hugging Face：6 个阶段 42 课 + 12 个探索任务 + 打卡连续天数 + 笔记 + 徽章。

## 使用

直接打开 https://logic77lhl.github.io/hf-quest/ 即可，进度存在浏览器 localStorage。

## 跨设备同步

用私有 Gist 当云存档：粘一个只有 `gist` 权限的 GitHub token → 创建存档 → 其他电脑粘同一个 token + Gist ID。合并规则见页面「云同步」标签。

## 说明

- 所有文档 / 模型链接默认走 `hf-mirror.com` 镜像（国内可直连 huggingface.co 时可在页面里切回官方）。
- token 只保存在各自浏览器的 localStorage，不写进本仓库、不进导出文件。
- 本页是纯静态文件，无后端、无第三方依赖、无统计脚本。
